Project Loom Demos

Demo 1: Virtual Threads (HTTP)

Baseline: A standard endpoint using a fixed thread pool. Under load, requests queue up waiting for threads.

Virtual: Uses Executors.newVirtualThreadPerTaskExecutor() to assign a cheap virtual thread to every request, improving throughput dramatically without changing the blocking code style.

Structured: Uses StructuredTaskScope to fan out downstream blocking calls concurrently within the request scope, improving latency and providing robust cancellation/failure handling.


    

  


  

    

      
Demo 2: Hybrid Reactive (Console)

      

        
This demo simulates a Hybrid Architecture. The ingress pipeline uses Reactive Streams to apply explicit backpressure, ensuring no more than 3 items are "in-flight" at a time to prevent resource exhaustion.

        
Once accepted by the reactive edge, the actual business logic is handed off to a Virtual Thread worker. This allows the system to remain responsive and backpressure-aware at the edge, while keeping the core business logic simple and blocking.
